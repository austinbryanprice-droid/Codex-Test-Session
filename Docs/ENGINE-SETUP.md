# Active engine setup

The active native project targets the owner's installed **UE 5.8.4**.
See [the native project README](../README.md) and run `Scripts/Setup-Windows.ps1`.
The historical UE 5.5.4 setup remains under `legacy/unreal` in the full repository.
A launcher-installed engine is sufficient for the Cedar Hollow editor/client.
A matching source engine is only needed for the separate dedicated server.
