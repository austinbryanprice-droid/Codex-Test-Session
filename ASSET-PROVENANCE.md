# Asset provenance

Browser artwork combines original project geometry/UI with verified CC0 photographic materials and an HDR panorama from Poly Haven. No Epic assets or purchased models are shipped.

| Asset | Authoring source | Usage |
| --- | --- | --- |
| Original fallback meadow/asphalt/concrete and active armor, roof, rubber, steel maps | `scripts/generate-textures.py` | Original deterministic 2K PBR texture sets |
| Original fallback HDR and active smoke alpha sprite | `scripts/generate-textures.py` | Original lighting/effects source |
| Legacy vehicle, soldier, architecture and tree geometry | `client/src/scene.ts` | Original runtime geometry retained outside the revised benchmark |
| Emblem, unit symbols, tactical map | React/SVG source | Original UI artwork |
| Sound cue | Web Audio oscillator code | Original synthesized transient |
| UI typography | System font stack | No font files redistributed |

Generated textures are original project content; this file does not impose a new repository-wide software license. Third-party software packages retain their own licenses in `node_modules`; preserve notices when distributing dependencies. Unreal references are archived under `legacy/unreal` and excluded from browser builds and container context.

Git LFS covers binary texture files. Run `git lfs install` and `git lfs pull` after cloning. Source-based regeneration requires Python, Pillow, NumPy, and SciPy. Keep asset-source and license records for any future downloaded content; do not infer browser redistribution rights from the word “free.”

Additional original detail assets: `tread-imprint.png`, `fluid-stain.png`, `rain-streaks.png`, and `vehicle-markings.png`, generated by `scripts/generate-detail-textures.py`. No external images are included in these decals.

## Modern realism benchmark additions

- Tank and rifleman GLBs: original Blender authoring in `scripts/art/build-models.py`, including three LODs, skeletal actions, bevelled geometry and UVs. No external military models.
- Paint texture: original `scripts/art/paint.py`. Other authored material inputs now live in `art-source/textures/`; compressed runtime copies are generated with Basis Universal.
- KTX2 decoder and WASM: `@babylonjs/ktx2decoder` 9.32.0. Its distributed WASM license is preserved at `client/public/vendor/ktx2/license.md`; the package uses Apache-2.0 and bundled codecs retain their notices.
- Basis Universal encoder: pinned `@gpu-tex-enc/basis` 1.16.4, Apache-2.0; build-time dependency, not a game art license.
- Active meadow, soil, gravel, asphalt, concrete and overcast lighting now use the CC0 sources below. Original inputs are preserved outside the public directory.

## Reference fidelity continuation — 2026-10-26

- Meadow now uses [Leafy Grass](https://polyhaven.com/a/leafy_grass), Charlotte Baglioni, CC0; dirt tracks use [Brown Mud Dry](https://polyhaven.com/a/brown_mud_dry), Rob Tuytel, CC0. The previous scans remain archived outside the shipped payload. Download size/MD5 and local SHA-256 are recorded in `art-source/polyhaven/provenance.json`.
- Added [Fir Sapling](https://polyhaven.com/a/fir_sapling), CC0. Exact author metadata, source files and checksums are in `art-source/scenery/provenance.json`. The selected variant is `fir_sapling_a`; LODs preserve complete needle components instead of collapsing their triangles.
- Broadleaf sprigs are original arrangements of twelve photographed leaflets cropped from the existing CC0 tree atlas. All derived maps remain credited to their source. Geometry and texture generation are reproducible with `build-scenery.py` and `prepare-scenery.py`.
- Tank camouflage and fine coating normals are original baked artwork in `build-models.py`. The reconnaissance vehicle is original geometry, UVs and camouflage from `build-recon.py` with shared authoring helpers in `model_helpers.py`. Three LODs and exact-model portraits are included.
- Reference-game images supplied in chat were inspected for visual principles only. They are not textures, models, backgrounds or other shipped game assets.

Mature conifer replacement: [Poly Haven fir_tree_01](https://polyhaven.com/a/fir_tree_01),
CC0-1.0; photography by Rob Tuytel and modeling by Rico Cilliers. The selected
`fir_tree_01_a_LOD0` is approximately 18.93 m tall. Runtime derivatives retain
whole needles and simplify woody geometry separately across three LODs. The
original 478 MB geometry buffer is staged under `art-source/`, not distributed
as part of the match download. The earlier fir sapling source remains archived;
its runtime material maps are replaced by the mature fir's maps.

Meadow ground cover also uses an original runtime alpha atlas authored in
`client/src/meadow-grass.ts`: tapered curved blade silhouettes, not third-party
photographs. Crossed clumps are spatially instanced, receive world shadows, and
sway in wind. The ground underneath continues to use verified CC0 photographic
PBR maps. This shader/atlas artwork carries the project's original-artwork
provenance and adds no external downloads.
