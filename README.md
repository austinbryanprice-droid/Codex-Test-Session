# Cedar Hollow browser preview

Static production build of the tiny woodland graphics world in Codex-Test-Session.

Configure Settings → Pages → Deploy from a branch → gh-pages → / (root).
Expected URL after GitHub finishes deploying:
https://austinbryanprice-droid.github.io/Codex-Test-Session/

No game server is required. WASD moves, F toggles flight, Escape releases the mouse.
The default route opens Cedar Hollow. Asset paths include /Codex-Test-Session/.
